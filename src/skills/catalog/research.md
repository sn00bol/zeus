# Research

Investigate a question by gathering, comparing, and evaluating sources so the user gets a grounded answer rather than an uncited guess.

## When to use
Use this skill when the user wants research, a literature overview, source evaluation, citations, fact-checking, a bibliography, or evidence from multiple independent references.
Typical phrasing includes looking up current events, comparing claims, asking what reputable sources say, requesting a citation or source, or evaluating literature reports.

## Task
Produce a useful answer that separates verified points from uncertain ones, and that makes the quality of the evidence visible.

## Process
1. Clarify the question being investigated and what would count as a sufficient answer.
2. Identify what kinds of sources would be appropriate (primary documents, official docs, peer-reviewed work, reputable reporting).
3. Prefer independent sources over a single restated claim. Note disagreements instead of hiding them.
4. Evaluate each source: who produced it, how recent it is, whether it is primary or secondary, and whether it actually supports the claim.
5. Synthesize: lead with the best-supported conclusion, then caveats and open questions.
6. Attribute claims. If you cannot verify something, say so rather than inventing a citation.

## Constraints
Do not perform HTTP requests, scraping, access control, retries, or error handling in this skill. Those belong to tools or runtime.
If no research or network tool is available, work only from conversation context and clearly labeled general knowledge. Do not pretend that pages were fetched.
Do not pad the answer with fake URLs, fake quotes, or fabricated publication details.
